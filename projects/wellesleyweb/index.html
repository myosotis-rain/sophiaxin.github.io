Overview

Pre-professional networking platform specifically designed for Wellesley College students and alumni in tech and tech-adjacent fields. Built front-end and back-end entirely from scratch as a team project.

The platform addresses the unique networking challenges faced by students transitioning from academia to the technology industry, providing tailored features for pre-professional connections, mentorship opportunities, and career development within the Wellesley community.

Key Features

  • Authentication System User authentication and profile management system with secure login and personalized user experiences.
  • Networking Platform Professional networking capabilities with advanced search and filtering for targeted connections.
  • Database Integration Comprehensive database integration for user data, connections, and platform interactions.
  • Responsive Design Responsive design implementation working seamlessly across all device sizes and platforms.
  • Full-Stack Architecture Complete full-stack architecture built from the ground up with modern web development practices.
