Work / Dovekie Interface

Dovekie Interface

Open-Source Live Coding Interface at MIT Media Lab

Role Interface Designer & Developer
Organization MIT Media Lab - Future Sketches Group
Supervisor Jessica Stringham
Year 2024

Project Overview

Implemented the Dovekie (open-source live coding JS package) interface and designed key interactive components. Created p5.js sketches to experiment with dynamic, parameter-driven generative workflows.

As part of the Future Sketches group at MIT Media Lab, I contributed to the development of an open-source live-coding environment that enables creative expression through code. The project focused on creating intuitive interfaces that bridge the gap between technical complexity and artistic creativity.

Key Contributions

  • Designed and implemented user interface components for the Dovekie live-coding environment
  • Created p5.js sketches demonstrating dynamic, parameter-driven generative workflows
  • Collaborated with the development team on interface usability and user experience improvements
  • Contributed to open-source documentation and community resources

Technical Approach

The interface design process involved understanding the unique needs of live-coding practitioners and translating complex technical requirements into intuitive user interactions. Key considerations included real-time feedback, parameter manipulation, and seamless integration with existing creative workflows.

Technologies

JavaScript p5.js Interface Design Live Coding Open Source

Impact

Contributed to an open-source tool that enables creative live-coding experiences for artists and developers worldwide.
