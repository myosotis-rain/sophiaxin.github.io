Case Study

Dovekie Interface

Interface design for open-source live-code package at MIT Media Lab, including molds simulation sketch collaboration.

Role · Product Design Timeline · 2023 Team · MIT Media Lab Stack · p5.js, Electron
Goal Make live-coding approachable
Focus Feedback clarity
Impact Higher engagement

Overview

Built a performant interface for live-coding that keeps accessibility front and center while enabling fast iteration and visual feedback. Partnered closely with engineers to translate research sketches into production UI.

Responsibilities

  • UX research & workflow mapping
  • Interaction design & prototyping
  • Design system tokens & documentation
  • Developer handoff & QA

Challenge → Process → Outcome

Challenge

New users struggled to understand what changed in each edit. The interface needed to surface feedback without interrupting flow.

Process

Created a three-layer model—inline hints, timeline, and full-screen simulation—to match different fidelity needs. Paired design reviews with weekly prototyping sprints.

Outcome

Reduced onboarding friction and improved retention metrics after launch. Code readability and state clarity increased for collaborators.

Process highlights

  • Mapped live coding states to visual tokens for consistent feedback
  • Prototyped inline diffing, modal timeline, and sandbox views
  • Documented API hooks for designers to attach new renderers

Key takeaways

Designing for live systems benefits from clear “trust cues” (state tags, save indicators) and progressive disclosure. Accessibility checks early prevented regressions later.
