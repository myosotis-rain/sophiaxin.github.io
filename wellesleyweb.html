The Wellesley Web: TechConnect

Pre-professional Networking Platform for Tech Students & Alumni

Role Full-Stack Developer
Course CS304 - Databases with Web Interfaces
Team 3 Students
Year 2024

Project Overview

Pre-professional networking platform specifically designed for Wellesley College students and alumni in tech and tech-adjacent fields. Built front-end and back-end entirely from scratch as a team project.

The platform addresses the unique networking challenges faced by students transitioning from academia to the technology industry, providing tailored features for pre-professional connections, mentorship opportunities, and career development within the Wellesley community.

Technical Challenge

This project presented significant technical challenges as I had to learn HTML and CSS from scratch while simultaneously implementing complex database interactions and full-stack architecture. The learning curve involved mastering both frontend technologies and backend database design within a single semester.

Despite starting with zero prior knowledge in frontend technologies, the team successfully delivered a fully functional networking platform with user authentication, database integration, and responsive design.

Key Features

  • User authentication and profile management system
  • Professional networking capabilities with search and filtering
  • Database integration for user data and connections
  • Responsive design working across all device sizes
  • Full-stack architecture built from the ground up
  • Mentorship matching and communication features

Technologies

Python HTML CSS JavaScript SQL Flask

Learning Outcomes

  • • Full-stack development
  • • Database design & integration
  • • Frontend development from scratch
  • • Team collaboration & version control
  • • User experience design

Impact

Successfully delivered a fully functional networking platform, gaining comprehensive full-stack development experience from zero prior knowledge in frontend technologies.
